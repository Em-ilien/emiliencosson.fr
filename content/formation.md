# Formation technique

<p class="subtitle">Montez en compétences avec des formations adaptées à vos besoins</p>

## Pourquoi investir dans la formation technique ?

Dans un secteur en perpétuelle évolution, la formation continue est un levier stratégique
pour rester compétitif. Les technologies web évoluent rapidement : nouveaux frameworks,
nouvelles méthodologies, nouvelles bonnes pratiques. Former vos équipes, c'est garantir
leur autonomie, leur productivité et la qualité de vos projets.

Que vous souhaitiez adopter un nouveau framework, moderniser vos pratiques de développement
ou simplement consolider les bases de votre équipe, je vous propose des formations
sur-mesure adaptées à votre contexte et vos objectifs.

## Formations sur frameworks modernes

Je propose des formations approfondies sur les frameworks frontend et fullstack les plus
utilisés du marché, avec une approche pratique orientée projet.

### Svelte et SvelteKit

Svelte est un framework innovant qui compile vos composants en JavaScript optimisé,
offrant des performances exceptionnelles et une syntaxe intuitive. SvelteKit étend
ces capacités avec le rendu côté serveur, le routing et bien plus.

- Fondamentaux de Svelte : réactivité, composants, stores
- SvelteKit : routing, SSR, SSG, API endpoints
- Intégration avec des CMS headless et bases de données
- Déploiement et optimisation des performances

### React et Next.js

React reste le framework le plus utilisé pour le développement d'interfaces utilisateur.
Next.js apporte une couche fullstack puissante avec des fonctionnalités avancées.

- Composants fonctionnels et hooks
- Gestion d'état : Context API, Redux, Zustand
- Next.js : App Router, Server Components, API Routes
- Tests unitaires et intégration avec Jest et Testing Library

### Vue.js et Nuxt

Vue.js offre une courbe d'apprentissage douce tout en permettant de construire des
applications complexes. Nuxt enrichit l'écosystème avec des outils fullstack.

- Composition API et Options API
- Gestion d'état avec Pinia
- Nuxt 3 : auto-imports, server routes, modules
- Migration de Vue 2 vers Vue 3

## Accompagnement d'équipes internes

Au-delà des sessions de formation classiques, je propose un accompagnement personnalisé
pour vos équipes de développement. Cette approche permet d'ancrer les apprentissages
dans la réalité de vos projets.

- **Audit de code** : analyse de votre base de code existante avec recommandations d'amélioration
- **Pair programming** : sessions de développement en binôme pour transférer les compétences en situation réelle
- **Code review** : revue de code avec explications pédagogiques pour améliorer les pratiques
- **Mentorat** : suivi individuel ou collectif sur plusieurs semaines pour accompagner la montée en compétences
- **Architecture** : aide à la conception d'architectures scalables et maintenables

Cet accompagnement peut se faire en complément de sessions de formation ou de manière
indépendante, selon vos besoins et votre organisation.

## Formats de formation

Je m'adapte à vos contraintes organisationnelles et propose plusieurs formats
pour répondre au mieux à vos besoins.

### Formation en présentiel

Les sessions en présentiel favorisent l'interaction et l'apprentissage collectif.
Elles sont idéales pour les formations d'équipe et les ateliers pratiques.

- Sessions dans vos locaux ou en espace de coworking
- Durée adaptable : demi-journée, journée complète ou sessions sur plusieurs jours
- Support de cours et exercices pratiques fournis
- Intervention possible dans toute la France

### Formation en distanciel

Les formations à distance offrent flexibilité et accessibilité, sans compromis
sur la qualité pédagogique.

- Sessions en visioconférence avec partage d'écran
- Enregistrement des sessions pour révision ultérieure
- Environnements de développement partagés (CodeSandbox, StackBlitz)
- Suivi asynchrone par messagerie pour les questions entre sessions

### Format hybride

Combinez les avantages des deux formats avec une approche hybride : sessions
présentilles pour les ateliers pratiques et suivi à distance pour l'accompagnement
continu.
